# 🧱 Crud/Landing Page Constroo

- O Constroo tem como foco principal a ligação entre o 🏗️ vendedor e o 🛒 comprador de materiais de construção com a possibilidade de serem reutilizados.

### 📌 Objetivo
Este repositório tem como objetivo a integração do Servlet com a landing page e o banco de dados, também sendo utilizado para escrever os comentários do código.
## 🛠️ Linguagens utilizadas 

### Backend:

- [JAVA ☕](https://www.oracle.com/java/technologies/downloads/)

### Frontend:

- [JAVA ☕](https://www.oracle.com/java/technologies/downloads/)

- [HTML 📄](https://www.w3schools.com/html/) e [CSS 🎨](https://www.w3schools.com/css/css_link.asp);

### Banco de dados:

- [PostgreSQL](https://www.postgresql.org/)

## 📚 Aprendizados

O Constroo é uma plataforma que conecta vendedores e compradores de materiais de construção reutilizáveis. O repositório integra Servlets com a landing page e o banco de dados, utilizando Java para backend e frontend, além de HTML, CSS e PostgreSQL. O projeto é colaborativo, desenvolvido por vários autores e licenciado sob MIT, permitindo uso comercial. Para instalar, é necessário clonar o repositório, configurar variáveis de ambiente e executá-lo em uma IDE como IntelliJ. Empresas como a ConstruConecta utilizam essa solução, e o suporte está disponível via e-mail ou Slack.
